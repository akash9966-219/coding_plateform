739. Daily Temps

Return an array where each entry is the number of days you have to wait for a warmer temperature.
Example 1:
Input: [73, 74, 75, 71, 69, 72, 76, 73]
Output: [1, 1, 4, 2, 1, 1, 0, 0]
Logic:
1. Stack: Maintain indices of temps in decreasing order.
2. Warmer Day: When curr > stack.top(), a warmer day is found.
3. Pop: Calculate the difference in indices for all such elements.
4. Efficiency: Each index is pushed and popped exactly once.
Complexity:
  • Time: O(n) - Single pass through the input.
  • Space: O(n) - Stack stores indices.
