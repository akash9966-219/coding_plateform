128. Longest Consecutive

Find the length of the longest consecutive elements sequence in an unsorted array.
Example:
Input: [100, 4, 200, 1, 3, 2]
Output: 4 (Sequence: [1, 2, 3, 4])
Logic:
1. Hash Set: Insert all elements for $O(1)$ lookups.
2. Find Start: Only start counting if (n - 1) is not in the set.
3. Build Chain: While (n + 1) exists, increment length.
Guarantees $O(n)$ because each element is visited constant times.
Complexity:
  • Time: O(n)
  • Space: O(n)
