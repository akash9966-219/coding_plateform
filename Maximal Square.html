221. Maximal Square

Find the largest square containing only 1's in a binary matrix and return its area.
Visual Reference:
DP Logic:
dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
Complexity:
  • Time: O(m * n)
  • Space: O(n) (Using 1D array optimization)
