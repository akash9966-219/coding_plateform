1141. User Activity for the Past 30 Days I

Table: Activity
Column NameType
user_idint
session_idint
activity_datedate
activity_typeenum
The table contains user activity logs.
A Daily Active User (DAU) is a unique user who performed at least one activity on a specific day.
Problem Statement
Find the daily active user count for a period of 30 days ending 2019-07-27 inclusively.
Example 1 Input
user_idactivity_dateactivity_type
12019-07-20open_session
12019-07-20scroll_down
22019-07-20open_session
42019-06-25open_session
Output:
dayactive_users
2019-07-202
2019-07-212
Explanation:
User 4's activity (06-25) is outside the 30-day window (06-28 to 07-27).
On 07-20, Users 1 and 2 were active. Count = 2.
