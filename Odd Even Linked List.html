328. Odd Even Linked List

Given the head of a singly linked list, group all nodes with odd indices together followed by even indices. Relative order inside both groups must be preserved. Solve in O(1) space and O(n) time.
Sample Test Cases:
Input (head) Output (reordered)
[1, 2, 3, 4, 5] [1, 3, 5, 2, 4]
[2, 1, 3, 5, 6, 4, 7] [2, 3, 6, 7, 1, 5, 4]
In-Place Logic:
Initial: (1) -> (2) -> (3) -> (4) -> (5)
         ^     ^
        odd   even (evenHead)

Step 1: (1) -> (3) , (2) -> (4)
Step 2: (3) -> (5) , (4) -> NULL
Final: (1)->(3)->(5) -> (2)->(4)->NULL
Complexity:
  • Time: O(n) - Single linear traversal.
  • Space: O(1) - Pointers reused; no extra storage used.
