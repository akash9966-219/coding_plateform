394. Decode String

Given an encoded string, return its decoded version. The encoding rule is: k[encoded_string], where the encoded_string inside the square brackets is being repeated exactly k times.
Examples:
Example 1:
Input: s = "3[a]2[bc]"
Output: "aaabcbc"
Logic:
1. Multi-Stack/Recursive: Use stacks for counts and strings, or recursion to handle nested brackets.
2. Multiplier: Capture numbers (including multi-digit) to know how many times to repeat.
3. Bracketing: Resolve inner brackets before appending them to the outer string.
4. Result: Concatenate the segments into a final decoded result.
Complexity:
  • Time: O(Output Length) - Proportional to the number of characters in the result.
  • Space: O(Max Depth) - Based on the maximum nesting level of the brackets.
