106. Build Tree (In/Post)

Construct a binary tree from its inorder and postorder traversal arrays.

Note: In postorder traversal, the root node appears at the very end of the array.
Example 1:
Input: inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]
Output: [3,9,20,null,null,15,7]
Logic Note:
Since postorder is (Left, Right, Root), we process from the end of postorder and build the Right child first.
