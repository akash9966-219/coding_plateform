75. Sort Colors

Sort an array containing 0s, 1s, and 2s in-place. Use a one-pass algorithm with constant space.
Example 1:
Input: nums = [2,0,2,1,1,0]
Output: [0,0,1,1,2,2]
Logic:
1. Three Pointers: low (0s boundary), mid (iterator), high (2s boundary).
2. Swap 0: Swap mid with low, increment both.
3. Stay 1: Increment mid only.
4. Swap 2: Swap mid with high, decrement high.
Complexity:
  • Time: O(n) - Single pass through the array.
  • Space: O(1) - In-place swaps only.
