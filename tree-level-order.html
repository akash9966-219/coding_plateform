102. Level Order

Return the level order traversal of a binary tree's nodes' values (layer by layer, left to right).
Example Reference:
BFS Logic (Queue):
1. Initialize: Queue with Root.
2. Snapshot: current_level_size = queue.size().
3. Process: Dequeue N nodes, enqueue their children.
Result: List of Lists
Complexity:
  • Time: O(n) - Every node visited once.
  • Space: O(n) - Queue size at the widest level.
