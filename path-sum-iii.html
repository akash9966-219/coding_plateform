437. Path Sum III

Find the number of paths that sum to targetSum. Paths must go downwards but do not need to start at the root.
Visual Reference:
Prefix Sum Strategy:
1. Map: Track frequencies of prefix sums.
2. Search: If currSum - targetSum exists in map, add count.
3. Backtrack: Remove currSum from map after processing children.
Complexity:
  • Time: O(n) - Single pass with hash map.
  • Space: O(n) - Recursion and map storage.
