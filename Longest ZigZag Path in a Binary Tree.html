1372. Longest ZigZag Path

Find the longest ZigZag path in a binary tree. A ZigZag path consists of nodes where the direction changes at each step (Right -> Left -> Right...).
Sample Test Case:
Root Array Longest ZigZag
[1,null,1,1,1,null,null,1,1,null,1,null,null,null,1,null,1] 3
State Logic:
dfs(node, goLeft, length):
  maxVal = max(maxVal, length)
  if goLeft:
    dfs(node.left, false, length + 1) // Switch
    dfs(node.right, true, 1) // Reset
  else:
    dfs(node.right, true, length + 1) // Switch
    dfs(node.left, false, 1) // Reset
Complexity:
  • Time: O(n) - Linear traversal of all nodes.
  • Space: O(h) - Call stack depth proportional to tree height.
