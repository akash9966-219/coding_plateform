169. Majority Element

Return the element that appears more than ⌊n / 2⌋ times. Solve in linear time and constant space.
Example 2:
Input: nums = [2,2,1,1,1,2,2]
Output: 2
Logic:
1. Initialize: Start with count = 0 and a candidate.
2. Vote: If count == 0, set candidate = current.
3. Update: If current == candidate, count++; else count--.
4. Result: The majority element is guaranteed to be the final candidate.
Complexity:
  • Time: O(n) - Single pass through the array.
  • Space: O(1) - Only two variables (count and candidate).
