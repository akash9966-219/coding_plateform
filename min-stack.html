155. Min Stack

Design a stack that supports push, pop, top, and retrieving the minimum element in constant time.
Logic:
1. Snapshots: Store the current minimum at every level of the stack.
2. Push: New min = min(val, lastMin).
3. Pop: Automatically reveals the previous minimum.
4. Result: All operations take O(1) time.
Complexity:
  • Time: O(1) for all operations.
  • Space: O(n) - Storing two values per entry.
