4. Median of Two Arrays

Given two sorted arrays, return the median. Time complexity must be O(log (m+n)).
Binary Search logic:
Partition A into leftA, rightA
Partition B into leftB, rightB

If max(leftA) <= min(rightB) and max(leftB) <= min(rightA):
Partition Found!
Complexity:
  • Time: O(log(min(m, n)))
  • Space: O(1)
