212. Word Search II

Given a board of characters and a dictionary, return all words that can be formed by adjacent cells. This is optimized by using a Trie to check for prefixes during DFS.
Example 1:
Input: words = ["oath","pea","eat","rain"]
Output: ["eat","oath"]
Constraints:
  • m, n ≤ 12
  • words[i].length ≤ 10
  • Trie size ≤ 3 * 104 words.
