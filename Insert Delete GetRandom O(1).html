380. Insert Delete GetRandom O(1)

Implement the RandomizedSet class:

* insert(int val): Inserts val if not present. Returns true if inserted.
* remove(int val): Removes val if present. Returns true if removed.
* getRandom(): Returns a random element. Each element must have the same probability.

You must implement these such that each function works in average O(1) time complexity.
Example:
Input: ["RandomizedSet", "insert", "remove", "insert", "getRandom"]
[[], [1], [2], [2], []]
Output: [null, true, false, true, 2]
Constraints:
  • -231 <= val <= 231 - 1
  • At most 2 * 105 calls will be made.
