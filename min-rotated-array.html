153. Find Min in Rotated Array

Find the minimum element in a sorted array that has been rotated. Complexity: O(log n).
Binary Search Strategy:
1. If nums[mid] > nums[high]:
   Inflection is to the right → low = mid + 1
2. Else:
   Inflection is at mid or left → high = mid
Target: nums[low]
Complexity:
  • Time: O(log n)
  • Space: O(1)
