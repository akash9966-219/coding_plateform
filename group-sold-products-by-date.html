There is no primary key. The table contains duplicate rows (e.g., Mask on 2020-06-02).
Problem Statement
For each date, find the number of different products sold and their names.
  • Product names must be sorted lexicographically.
  • Separate names by a comma.
Return the result table ordered by sell_date.
Output:
sell_datenum_soldproducts
2020-05-303Basketball,Headphone,T-Shirt
2020-06-012Bible,Pencil
2020-06-021Mask
Explanation:
- 2020-05-30: Sold (Headphone, Basketball, T-Shirt). Sorted: Basketball,Headphone,T-Shirt.
- 2020-06-01: Sold (Pencil, Bible). Sorted: Bible,Pencil.
- 2020-06-02: Sold (Mask, Mask). Distinct count is 1. Sorted: Mask.
