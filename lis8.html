1964. Longest Obstacle Course

Description

You want to build some obstacle courses. You are given an array obstacles. For every index i, you must find the length of the longest valid obstacle course that ends at index i.

A course is valid if you choose any number of obstacles between index 0 and i such that the heights are non-decreasing.

Example
Input obstacles = [1,2,3,2]
Output [1,2,3,3]
Explanation At index 3, the longest course is [1,2,2] or [1,2,3]. Length is 3.
