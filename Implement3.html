337. House Robber III

Description

The thief has found a new place for his thievery. There is only one entrance to this area, called the "root." Besides the root, each house has one and only one parent house.

If two directly-linked houses were broken into on the same night, the police will automatically be contacted. Return the maximum amount of money the thief can rob without alerting the police.

Example
Input root = [3,2,3,null,3,null,1]
Output 7
Explanation Maximum amount of money the thief can rob = 3 + 3 + 1 = 7.
