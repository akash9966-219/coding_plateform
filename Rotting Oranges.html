994. Rotting Oranges

You are given an m x n grid where 0 is empty, 1 is fresh, and 2 is rotten. Every minute, any fresh orange that is 4-directionally adjacent to a rotten orange becomes rotten. Return the minimum minutes to rot all fresh oranges.
Sample Test Case:
GridOutput
[[2,1,1],[1,1,0],[0,1,1]]4
[[2,1,1],[0,1,1],[1,0,1]]-1
Multi-Source BFS Logic:
1. Queue q = all initial rotten oranges (2)
2. count fresh_oranges (1)
3. while q and fresh > 0:
   for each orange in current q:
     infect adjacent fresh neighbors
     q.push(newly_rotten), fresh--
   minutes++
4. return fresh == 0 ? minutes : -1
Complexity:
  • Time: O(M * N) - Visit each cell at most twice.
  • Space: O(M * N) - Queue storage for all oranges.
