73. Set Matrix Zeroes

If an element in an m times n matrix is 0, set its entire row and column to 0. Do it in-place with constant space.
Example 1:

Input: [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
Logic:
1. Flags: Use boolean flags for first row/column.
2. Markers: Use matrix[i][0] and matrix[0][j] to record zeroes for internal cells.
3. Fill: Traverse internal cells and set to 0 if markers are 0.
4. Finalize: Apply the initial row/col flags.
Complexity:
  • Time: O(M * N) - Two full passes.
  • Space: O(1) - Marker logic is in-place.
