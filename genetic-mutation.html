433. Min Genetic Mutation

Description

A gene string can be represented by an 8-character long string, with choices from 'A', 'C', 'G', and 'T'.

Given two gene strings start and end and a gene bank, return the minimum number of mutations needed to transform start to end. If there is no such a mutation, return -1.

Example
Input start = "AACCGGTT", end = "AACCGGTA", bank = ["AACCGGTA"]
Output 1
