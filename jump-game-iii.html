1306. Jump Game III

Description

Given an array of non-negative integers arr and a start index start. When you are at index i, you can jump to i + arr[i] or i - arr[i].

Return true if you can reach any index with value 0.

Example
Input arr = [4,2,3,0,3,1,2], start = 5
Output true
Explanation 5 -> 4 -> 1 -> 3 (value 0)
