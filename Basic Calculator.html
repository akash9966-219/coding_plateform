224. Basic Calculator

Implement a basic calculator to evaluate a valid expression string containing digits, +, -, (, ), and spaces.

Note: The - character can be used as a unary operator.
Example 3:
Input: s = "(1+(4+5+2)-3)+(6+8)"
Output: 23
Constraints:
  • 1 <= s.length <= 3 * 105
  • All calculations fit in a 32-bit signed integer.
