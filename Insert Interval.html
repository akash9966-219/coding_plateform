57. Insert Interval

Insert a newInterval into a sorted array of non-overlapping intervals. Maintain the sorted order and merge any overlapping intervals.
Example 2:
Input: intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
Output: [[1,2],[3,10],[12,16]]
Explanation: [4,8] overlaps with [3,5],[6,7],[8,10], merging into [3,10].
Constraints:
  • 0 <= intervals.length <= 104
  • 0 <= starti <= endi <= 105
  • Intervals are sorted by start time.
