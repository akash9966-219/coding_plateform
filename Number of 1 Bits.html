191. Number of 1 Bits

Write a function that takes a positive integer and returns the number of set bits (1s) in its binary representation.
Optimization Logic:

Brian Kernighan's Algorithm

n = n & (n - 1)

This operation removes the rightmost '1'. Repeat until n = 0.

Follow-up:
If called many times, use a precomputed lookup table for 8-bit or 16-bit chunks, or use built-in functions like Integer.bitCount(n) in Java or __builtin_popcount(n) in C++.
