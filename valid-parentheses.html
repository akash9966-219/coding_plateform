20. Valid Parentheses

Determine if an input string containing only brackets is valid.
Example 4:
Input: s = "([])"
Output: true
Logic:
1. Stack: Push opening brackets onto the stack.
2. Match: For closing brackets, pop and check if types match.
3. Order: LIFO ensures inner brackets are closed before outer ones.
4. Result: Return true if stack is empty at the end.
Complexity:
  • Time: O(n) - Single pass through the string.
  • Space: O(n) - Worst case all opening brackets.
