199. Right Side View

Imagine yourself standing on the right side of a binary tree. Return the values of the nodes you can see ordered from top to bottom.
Example 1:
Input: root = [1,2,3,null,5,null,4]
Output: [1,3,4]
Constraints:
  • The number of nodes is in range [0, 100].
  • -100 <= Node.val <= 100
