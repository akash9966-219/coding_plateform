345. Reverse Vowels

Given a string s, reverse only all the vowels in the string and return it. Vowels are 'a', 'e', 'i', 'o', and 'u', in both cases.
Examples:
Example 1:
Input: s = "IceCreAm"
Output: "AceCreIm"
Example 2:
Input: s = "leetcode"
Output: "leotcede"
Logic:
1. Pointers: Set i = 0 and j = s.length - 1.
2. Search: Move i right until a vowel is found; move j left until a vowel is found.
3. Swap: Swap s[i] and s[j], then move both inward.
4. Case: Ensure check includes both uppercase and lowercase vowels.
Complexity:
  • Time: O(n) - Single pass with two pointers.
  • Space: O(n) - To store the character array/result string.
