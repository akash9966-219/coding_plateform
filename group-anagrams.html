49. Group Anagrams

Given an array of strings strs, group the anagrams together. You can return the answer in any order.
Example:
Input: ["eat","tea","tan","ate","nat","bat"]
Output: [["bat"],["nat","tan"],["ate","eat","tea"]]
Logic:
1. Categorize: Anagrams have the same characters.
2. Key Generation: Sort each string to create a unique key.
3. Grouping: Map identical keys to a shared list of strings.
C uses a struct-sort approach to simulate grouping.
Complexity:
  • Time: O(n * k log k)
  • Space: O(n * k)
