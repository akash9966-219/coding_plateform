139. Word Break

Return true if the string s can be segmented into a space-separated sequence of one or more dictionary words.
DP Logic:

s = "leetcode", dict = ["leet", "code"]

dp[0] = T (Empty)
dp[4] = dp[0] && "leet" is in dict → T
dp[8] = dp[4] && "code" is in dict → T
Complexity:
  • Time: O(n3) - n2 for loops, n for substring slicing.
  • Space: O(n) for the DP array.
