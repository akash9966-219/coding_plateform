1857. Largest Color Value in a DAG

Description

There is a directed graph with n nodes and m edges. Each node has a color represented by a lowercase English letter.

Return the largest color value of any valid path in the graph, or -1 if the graph contains a cycle.

Example
Input colors = "abaca", edges = [[0,1],[0,2],[2,3],[3,4]]
Output 3
