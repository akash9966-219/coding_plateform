394. Decode String

Decode a string formatted as k[encoded_string], where the content inside brackets is repeated k times.
Example 2:
Input: s = "3[a2[c]]"
Output: "accaccacc"
Explanation: 3 * ("a" + 2 * "c")
Logic:
1. Stacks: Use countStack for numbers and resStack for strings.
2. '[': Push current number and current string, then reset both.
3. ']': Pop count and previous string, then build: prev + (current * count).
4. Digits/Chars: Update current number or append to current string.
Complexity:
  • Time: O(Output Length) - We visit each character of the result.
  • Space: O(Max Nesting Depth) - Stack size depends on brackets.
