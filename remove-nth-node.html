19. Remove Nth Node

Given the head of a linked list, remove the $n^{th}$ node from the end of the list and return its head.
Example 1:

Input: head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]
Logic:
1. Fast Pointer: Move fast $n+1$ steps forward.
2. Slow Pointer: Start slow at a dummy node.
3. Synchronize: Move both until fast is null.
4. Delete: slow.next = slow.next.next.
Complexity:
  • Time: O(L) - One pass over length L.
  • Space: O(1) - Only two pointers used.
