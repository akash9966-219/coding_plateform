389. Find the Difference

Description

You are given two strings s and t. String t is generated by random shuffling string s and then adding one more letter at a random position.

Return the letter that was added to t.

Example 1
Input s = "abcd", t = "abcde"
Output "e"
Key Insight

Because string t has exactly one extra character, the sum of character values in t minus the sum in s will equal the ASCII value of that extra character. Alternatively, XORing all characters will isolate the unique one.
