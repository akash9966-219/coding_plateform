841. Keys and Rooms

There are n rooms labeled from 0 to n - 1. All rooms are locked except room 0. You have keys to other rooms. Can you visit all rooms?
Sample Test Cases:
Input (rooms)Output
[[1],[2],[3],[]]true
[[1,3],[3,0,1],[2],[0]]false
Traversal Logic (DFS):
visited = [false] * n
stack = [0]
visited[0] = true

while stack:
  room = stack.pop()
  for key in rooms[room]:
    if not visited[key]:
      visited[key] = true
      stack.push(key)
Complexity:
  • Time: O(N + E) - N rooms, E total keys.
  • Space: O(N) - To store visited status and stack.
