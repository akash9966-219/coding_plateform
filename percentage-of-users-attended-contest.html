1633. Percentage of Users Attended a Contest

Table: Users
Column NameType
user_idint
user_namevarchar
user_id is the primary key. Contains the name and ID of every user.
Table: Register
Column NameType
contest_idint
user_idint
(contest_id, user_id) is the primary key. Records which user joined which contest.
Problem Statement
Find the percentage of users registered in each contest rounded to two decimals. Order by percentage (descending), then contest_id (ascending).
Example 1 Input

Users Table:

ID 6: AliceID 2: BobID 7: Alex

Total Users = 3

Register Table Snippet:

contest_iduser_id
2156
2157
2082
2086
2087
Output:
contest_idpercentage
208100.0
21566.67
Explanation:
Contest 208: 3 users registered / 3 total = 100%
Contest 215: 2 users registered / 3 total = 66.67%
