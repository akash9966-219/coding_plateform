1657. Strings Are Close

Determine if two strings are close based on swapping characters or transforming all occurrences of one character into another.
Examples:
Example 1:
Input: word1 = "abc", word2 = "bca"
Output: true (Direct swap possible)
Example 2:
Input: word1 = "cabbba", word2 = "abbccc"
Output: true (Frequencies: [1,2,3] for both)
Logic:
1. Length: If lengths differ, return false.
2. Characters: Check if both strings contain the same unique character set.
3. Frequencies: Count character frequencies and sort them. The sorted frequency arrays must be identical.
4. Efficiency: O(N) time with O(1) space (fixed size alphabet array).
Complexity:
  • Time: O(n) - One pass to count frequencies.
  • Space: O(1) - Constant size (26) arrays for counts.
