2352. Equal Row and Column Pairs

Given an n x n integer matrix grid, return the number of pairs (ri, cj) such that row ri and column cj are equal.
Examples:
Example 1:
Input: grid = [[3,2,1],[1,7,6],[2,7,7]]
Output: 1
Explanation: There is 1 equal row and column pair: (Row 2, Column 1) -> [2,7,7].
Logic:
1. Mapping Rows: Store the frequency of each row in a Hash Map. Use Arrays.toString() or tuples as keys.
2. Building Columns: Iterate through columns and build an array/list for each.
3. Counting: For each column, check if it exists in the row Map and add its frequency to the total.
4. Efficiency: O(n²) time complexity.
Complexity:
  • Time: O(n²) - Iterating through all rows and then all columns.
  • Space: O(n²) - To store row frequencies in the worst case.
