190. Reverse Bits

Reverse the bits of a given 32-bit unsigned integer. The result should be the integer formed by the reversed bit sequence.
Bitwise Step-by-Step:
1. res << 1 : Make space for next bit
2. n & 1 : Extract the last bit of input
3. res | bit : Append bit to result
4. n >> 1 : Move to next input bit
Follow-up Tip:
If called multiple times, divide the 32 bits into 4 chunks (8 bits each) and use a precomputed lookup table for all 256 possible byte values.
