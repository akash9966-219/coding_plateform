1143. Longest Common Subsequence

Given two strings text1 and text2, return the length of their longest common subsequence. If there is no common subsequence, return 0.
Sample Test Case:
text1text2Output
"abcde""ace"3
"abc""abc"3
"abc""def"0
DP Logic:
if text1[i] == text2[j]:
  dp[i][j] = 1 + dp[i-1][j-1]
else:
  dp[i][j] = max(dp[i-1][j], dp[i][j-1])
Complexity:
  • Time: O(m * n) - M and N are lengths of the strings.
  • Space: O(m * n) - Size of the 2D DP table.
