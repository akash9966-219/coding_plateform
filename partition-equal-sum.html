416. Partition Equal Sum

Return true if you can partition the array into two subsets with equal sums.
Examples:
Input: nums = [1,5,11,5]
Output: true ([1,5,5] and [11])
Input: nums = [1,2,3,5]
Output: false
0/1 Knapsack Logic:
1. Total Sum: Must be even. Target = Sum / 2.
2. DP Array: dp[target+1] stores reachable sums.
3. Inner Loop: Traverse backwards from target down to num.
4. Update: dp[i] = dp[i] || dp[i - num].
Complexity:
  • Time: O(n * targetSum)
  • Space: O(targetSum)
