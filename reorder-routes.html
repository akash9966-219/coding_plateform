1466. Reorder Routes

Description

There are n cities and n - 1 roads. Each road is directed.

Reorder some roads such that each city can visit city 0. Return the minimum number of roads that need to be changed.

Example
Input n = 6, connections = [[0,1],[1,3],[2,3],[4,0],[4,5]]
Output 3
