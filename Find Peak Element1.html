162. Find Peak Element

A peak element is an element that is strictly greater than its neighbors. Given an integer array nums, find a peak element and return its index. If the array contains multiple peaks, return the index to any of the peaks.
Sample Test Cases:
Input (nums)Output Index
[1,2,3,1]2
[1,2,1,3,5,6,4]1 or 5
Binary Search Logic:
while low < high:
  mid = low + (high - low) / 2
  if nums[mid] < nums[mid+1]:
    low = mid + 1 (Peak is to the right)
  else:
    high = mid (Peak is to the left or is mid)
Complexity:
  • Time: O(log n) - Dividing search space by half.
  • Space: O(1) - Iterative approach usage.
