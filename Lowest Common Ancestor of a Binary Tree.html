236. Lowest Common Ancestor

Find the lowest common ancestor (LCA) of two given nodes p and q.

The LCA is the lowest node in the tree that has both p and q as descendants.
Example 1:
Input: root = [3,5,1,6,2,0,8...], p = 5, q = 1
Output: 3
Constraints:
  • Number of nodes in range [2, 105].
  • All Node values are unique.
  • p and q are guaranteed to exist in the tree.
