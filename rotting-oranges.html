994. Rotting Oranges

Return the minimum minutes until no cell has a fresh orange. If impossible, return -1.
Examples:
Input: grid = [[2,1,1],[1,1,0],[0,1,1]]
Output: 4
Input: grid = [[2,1,1],[0,1,1],[1,0,1]]
Output: -1
Multi-Source BFS Logic:
1. Queue: Add all initial rotten oranges.
2. Fresh Count: Track total fresh oranges.
3. Loop: Process queue level-by-level (each level = 1 minute).
4. Spread: Turn adjacent fresh oranges rotten and add to queue.
Check if fresh count reaches 0.
Complexity:
  • Time: O(m * n) - Visit each cell once.
  • Space: O(m * n) - Queue size in worst case.
