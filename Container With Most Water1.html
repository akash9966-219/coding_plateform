11. Container With Most Water

Find two lines that form a container such that it holds the most water. Return the maximum area.
Examples:
Example 1:
Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
Explanation: Max area formed between index 1 (val 8) and index 8 (val 7). Width = 7, Height = 7.
Logic:
1. Two Pointers: Initialize left = 0 and right = n - 1.
2. Area Calculation: min(h[l], h[r]) * (r - l).
3. Greedy Move: Always move the pointer with the smaller height to search for a taller boundary.
4. Efficiency: O(n) time as each element is visited at most once.
Complexity:
  • Time: O(n) - Single pass with two pointers.
  • Space: O(1) - Constant auxiliary space.
