50. Pow(x, n)

Calculate x raised to the power n in O(log n) time using binary exponentiation.
Binary Exponentiation:

Example: 210 = (22)5 = 45

1. 210 → (2*2)5 = 45
2. 45 → 4 * 44 = 4 * (4*4)2 = 4 * 162
3. 162 → (16*16)1 = 2561
Result: 4 * 256 = 1024
Complexity:
  • Time: O(log n)
  • Space: O(1) iterative / O(log n) recursive
