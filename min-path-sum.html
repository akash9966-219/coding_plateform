64. Minimum Path Sum

Find a path from top-left to bottom-right in an m x n grid that minimizes the sum of all numbers along the path.
Example:
Input: grid = [[1,3,1],[1,5,1],[4,2,1]]
Output: 7
Visual Reference:
DP Logic:
1. Edges: Fill first row and column with cumulative sums.
2. Transition: For cell (i, j), dp[i][j] = grid[i][j] + min(top, left).
Target: dp[m-1][n-1]
Complexity:
  • Time: O(m * n)
  • Space: O(1) - If modifying input grid; O(n) otherwise.
