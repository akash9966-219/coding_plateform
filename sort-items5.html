1203. Sort Items Respecting Dependencies

Description

There are n items and m groups. Each item belongs to one group, or no group at all (indicated by -1).

Sort the items such that:

  • Items belonging to the same group are adjacent.
  • Item-level and group-level dependencies are respected.

Example
Input n = 8, m = 2, group = [-1,-1,1,0,0,1,0,-1], beforeItems = [[],[6],[5],[6],[3,6],[],[],[]]
Output [6,3,4,1,5,2,0,7]
