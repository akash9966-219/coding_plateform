643. Maximum Average Subarray I

Find a contiguous subarray of length k that has the maximum average value and return this value.
Examples:
Example 1:
Input: nums = [1,12,-5,-6,50,3], k = 4
Output: 12.75
Explanation: Maximum average is (12 - 5 - 6 + 50) / 4 = 51 / 4 = 12.75.
Logic:
1. Initial Sum: Calculate the sum of the first k elements.
2. Slide: Loop from i = k to n-1.
3. Update Sum: currentSum += nums[i] - nums[i-k].
4. Track Max: Keep the highest currentSum found.
5. Return: Return maxSum / (double)k.
Complexity:
  • Time: O(n) - Single pass through the array.
  • Space: O(1) - Constant space for sum and max variables.
