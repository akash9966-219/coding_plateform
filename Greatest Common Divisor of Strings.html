1071. GCD of Strings

Find the largest string x that divides both str1 and str2. A string divides another if it can be concatenated multiple times to form it.
Logic:
1. Condition: str1 + str2 must equal str2 + str1.
2. Math: The length of the GCD string is gcd(len1, len2).
3. Euclidean: Use the recursive GCD algorithm for the lengths.
4. Result: Return the substring from index 0 to the calculated GCD length.
Complexity:
  • Time: O(m + n) - For the string concatenation and comparison.
  • Space: O(m + n) - To store the concatenated strings.
