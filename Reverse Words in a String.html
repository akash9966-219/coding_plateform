151. Reverse Words in a String

Given an input string s, reverse the order of the words.

Note that s may contain leading or trailing spaces or multiple spaces between two words. The returned string should only have a single space separating the words.
Example 3:
Input: s = "a good example"
Output: "example good a"
Explanation: You need to reduce multiple spaces to a single space.
Follow up: If the string data type is mutable, can you solve it in-place with O(1) extra space?
