763. Partition Labels

Partition the string into as many parts as possible so that each letter appears in at most one part. Return the sizes of these parts.
Examples:
Input: s = "ababcbacadefegdehijhklij"
Output: [9, 7, 8]
Greedy Logic:
1. Last Occurrences: Record the last index of each character.
2. End Pointer: Track the farthest 'last index' of all characters in current chunk.
3. Partition: When i == end, we found a chunk. Store size and reset start.
O(n) time complexity.
Complexity:
  • Time: O(n) - Two linear passes.
  • Space: O(1) - Array of 26 integers for last indices.
