392. Is Subsequence

Given two strings s and t, return true if s is a subsequence of t, or false otherwise.

A subsequence is formed by deleting some characters without disturbing the relative positions of the remaining characters.
Example 1:
Input: s = "abc", t = "ahbgdc" Output: true
Constraints:
  • 0 <= s.length <= 100
  • 0 <= t.length <= 104
  • s and t consist only of lowercase English letters.
Follow up: For a massive number of queries $k \ge 10^9$, you should pre-process t using a Map of indices and use binary search to find the next valid character position.
