124. Max Path Sum

Return the maximum path sum of any non-empty path in a binary tree.

A path can start and end at any node and does not need to pass through the root.
Example 2:
Input: root = [-10,9,20,null,null,15,7]
Output: 42
Explanation: Path 15 -> 20 -> 7 has sum 42.
Constraints:
  • Number of nodes in range [1, 3 * 104].
  • -1000 <= Node.val <= 1000
