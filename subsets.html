78. Subsets

Given an integer array nums of unique elements, return all possible subsets (the power set).
Recursive Logic:
For each element at index i:
1. Push: Add nums[i] to current path.
2. Recurse: Call backtrack(i + 1).
3. Pop: Remove nums[i] (Backtrack).
Every node in the recursion tree is a valid subset.
Complexity:
  • Time: O(n * 2n) - 2n subsets, each takes O(n) to copy.
  • Space: O(n) - Recursive stack depth.
