2. Add Two Numbers

Represent two non-negative integers as linked lists where digits are in reverse order. Add them and return the sum list.
Example 1:
Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Math: 342 + 465 = 807
Example 2:
Input: l1 = [9,9,9], l2 = [1]
Output: [0,0,0,1]
Math: 999 + 1 = 1000
Logic:
1. Iterate: Traverse both lists simultaneously.
2. Sum: DigitSum = (v1 + v2 + carry).
3. Carry: Update carry = sum / 10 for next node.
4. Append: New node gets sum % 10.
Complexity:
  • Time: O(max(m, n))
  • Space: O(max(m, n))
