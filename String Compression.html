443. String Compression

Compress an array of characters in-place. Consecutive repeating characters should be replaced by the character followed by the group length (if > 1).
Examples:
Example 1:
Input: chars = ["a","a","b","b","c","c","c"]
Output: 6 (Array becomes ["a","2","b","2","c","3"])
Example 3:
Input: chars = ["a","b",...,"b"] (12 times)
Output: 4 (Array becomes ["a","b","1","2"])
Logic:
1. Two Pointers: i for reading groups, res for writing result.
2. Find Group: While j < n and chars[j] == chars[i], increment j.
3. Write Char: chars[res++] = chars[i].
4. Write Length: If j - i > 1, convert the diff to characters and write to res.
Complexity:
  • Time: O(n) - Single pass through the array.
  • Space: O(1) - Constant auxiliary space for counters.
