32. Longest Valid Parentheses

Given a string containing just '(' and ')', return the length of the longest well-formed parentheses substring.
Examples:
Input: s = "(()"
Output: 2
Input: s = ")()())"
Output: 4
Optimal Strategy:
1. Forward Pass: Count '(' and ')'. If equal, update max. If ')' > '(', reset.
2. Backward Pass: Same logic, but reset if '(' > ')'.
This ensures $O(n)$ time and $O(1)$ space.
Complexity:
  • Time: O(n) - Two linear passes.
  • Space: O(1) - Only a few integer counters.
