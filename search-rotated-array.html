33. Search Rotated Array

Search for target in a sorted array that has been rotated. Complexity must be O(log n).
Binary Search Strategy:
1. Find mid.
2. Determine if [low...mid] is sorted.
3. If yes, check if target is in range [low...mid].
4. Else, [mid...high] must be sorted. Check range.
Halve search space O(log n)
Complexity:
  • Time: O(log n)
  • Space: O(1)
