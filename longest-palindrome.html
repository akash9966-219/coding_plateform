5. Longest Palindromic Substring

Given a string s, return the longest palindromic substring in s.
Examples:
Input: s = "babad"
Output: "bab" (or "aba")
Input: s = "cbbd"
Output: "bb"
Expansion Strategy:
For each index i:
1. Odd Expansion: Center is s[i] (aba)
2. Even Expansion: Center is s[i], s[i+1] (abba)
3. Update start and end pointers for the longest match found.
Complexity:
  • Time: O(n2) - n centers, O(n) expansion per center.
  • Space: O(1) - In-place comparison.
