108. Sorted Array to BST

Convert a sorted array into a height-balanced Binary Search Tree.
Example Reference:
Recursive Partitioning:
1. Mid: (left + right) / 2
2. Node: Create node with nums[mid].
3. Left: Recurse on [left, mid - 1]
4. Right: Recurse on [mid + 1, right]
Complexity:
  • Time: O(n) - Visit each element once.
  • Space: O(log n) - Recursion depth for balanced tree.
