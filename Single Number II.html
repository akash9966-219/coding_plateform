137. Single Number II

Every element appears three times except for one. Find that element in O(n) time and O(1) space.
Logic: Bit Summation

Sum bits at each position across all numbers

Sum of bits at pos i: S
Unique number's bit at pos i = S % 3
Follow-up: Bitmask State
Using variables ones and twos creates a base-3 counter for each bit position.
