208. Implement Trie

Implement a Trie (Prefix Tree) to efficiently store and retrieve strings. Supports insert, search, and startsWith.
Logic:
1. Nodes: Each node has an array of size 26 for its children.
2. Insert: Traverse the path for the word, creating nodes as needed.
3. Search: Traverse the path; if a node is missing, the word isn't there.
4. Prefix: Same as search, but don't check the end-of-word flag.
Complexity:
  • Time: O(L) for all operations (L is length of string).
  • Space: O(N * L) total characters stored.
