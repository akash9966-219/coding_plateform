1466. Reorder Routes

Given n cities and connections representing directed roads. We want all paths to lead to city 0. Return the minimum number of roads that need to be flipped.
Sample Test Case:
Input (n, connections)Output
6, [[0,1],[1,3],[2,3],[4,0],[4,5]]3
BFS Logic:
1. Build bidirectional graph.
2. Edge u -> v: weight 1 (needs flip).
3. Edge v -> u: weight 0 (already leads to 0).
4. Start BFS at city 0 and sum edge weights.
Complexity:
  • Time: O(V + E) - Linear traversal.
  • Space: O(V + E) - Adjacency storage.
