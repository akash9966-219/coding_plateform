274. H-Index

Given an array of integers citations where citations[i] is the number of citations a researcher received for their ith paper, return the researcher's h-index.

The h-index is the maximum value of h such that the researcher has published at least h papers that have each been cited at least h times.
Example 1:
Input: citations = [3,0,6,1,5]
Output: 3
Explanation: The researcher has 5 papers. 3 papers have at least 3 citations each ([3, 6, 5]).
Example 2:
Input: citations = [1,3,1]
Output: 1
Constraints:
  • n == citations.length
  • 1 <= n <= 5000
  • 0 <= citations[i] <= 1000
