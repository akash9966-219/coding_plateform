63. Unique Paths II

Description

You are given an m x n integer array obstacleGrid. A robot is initially located at the top-left corner. The robot tries to move to the bottom-right corner.

The robot can only move either down or right. An obstacle and space are marked as 1 and 0 respectively. Return the number of unique paths.

Example
Input obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
Output 2
