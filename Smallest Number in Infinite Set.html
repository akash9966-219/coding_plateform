2336. Smallest in Infinite Set

Implement the SmallestInfiniteSet class:
  • popSmallest() Removes and returns the smallest integer.
  • addBack(num) Adds num back into the set if it is not already present.
Sample Test Case:

Internal State Logic:
Infinite set conceptual start: [1, 2, 3, 4, ...]

1. popSmallest(): No heap? Return nextSmallest (1). nextSmallest = 2.
2. addBack(1): 1 < 2? Add 1 to minHeap. addedSet = {1}.
3. popSmallest(): Heap has 1? Pop 1. Return 1.
Complexity:
  • popSmallest: O(log N) - Heap pop or O(1) - Pointer.
  • addBack: O(log N) - Heap push with O(1) set check.
  • Space: O(N) where N is unique addBack operations.
