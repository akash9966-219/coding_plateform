48. Rotate Image

Rotate an $n \times n$ 2D matrix by 90 degrees clockwise in-place. Do not allocate another matrix.
Example 1:

Input: [[1,2,3],[4,5,6],[7,8,9]]
Output: [[7,4,1],[8,5,2],[9,6,3]]
Logic:
1. Transpose: Swap matrix[i][j] with matrix[j][i].
2. Reflect: Reverse each row of the transposed matrix.
3. Result: The matrix is rotated 90° clockwise.
Complexity:
  • Time: O(N²) - We visit every element twice.
  • Space: O(1) - Constant space for swaps.
