1729. Find Followers Count

Table: Followers
Column NameType
user_idint
follower_idint
(user_id, follower_id) is the primary key.
Each row indicates a relationship where follower_id follows user_id.
Problem Statement
For each user, return the number of followers. Order the results by user_id in ascending order.
Example 1 Input
user_idfollower_id
01
10
20
21
Output:
user_idfollowers_count
01
11
22
Explanation:
User 0 is followed by 1. Count = 1.
User 1 is followed by 0. Count = 1.
User 2 is followed by 0 and 1. Count = 2.
