230. Kth Smallest

Given the root of a BST and an integer k, return the kth smallest value (1-indexed) of all nodes in the tree.
Follow Up:
If the tree is modified often, we can optimize by storing the subtree size at each node. This allows finding the kth element in O(log N) time.
Constraints:
  • 1 <= k <= n <= 104
  • 0 <= Node.val <= 104
