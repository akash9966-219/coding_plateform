46. Permutations

Given an array of distinct integers, return all possible permutations.
Backtracking (Swap) logic:
For each index i starting from 'start':
1. Swap: nums[start] ↔ nums[i]
2. Recurse: Solve for start + 1
3. Backtrack: Swap nums[start] ↔ nums[i] back
Base Case: start == nums.length
Complexity:
  • Time: O(n * n!) - n! permutations, each taking O(n) to copy.
  • Space: O(n) - Recursive stack depth.
