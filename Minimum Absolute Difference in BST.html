530. Min Diff in BST

Given the root of a Binary Search Tree, return the minimum absolute difference between the values of any two different nodes.
Core Logic:
Perform an In-order Traversal to process values in sorted order, then find the smallest gap between consecutive elements.
Constraints:
  • Number of nodes in range [2, 104].
  • 0 <= Node.val <= 105
