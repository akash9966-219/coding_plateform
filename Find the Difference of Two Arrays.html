2215. Find Difference

Given two integer arrays nums1 and nums2, return a list of two lists: one containing distinct integers in nums1 not in nums2, and vice versa.
Examples:
Example 1:
Input: nums1 = [1,2,3], nums2 = [2,4,6]
Output: [[1,3],[4,6]]
Logic:
1. Set Logic: Use HashSets (or Sorting + Two-Pointers in C) to find elements present in one set but not the other.
2. Handling Duplicates: Sets automatically handle duplicates; in C, we pre-sort and extract unique values manually.
3. Fast Lookup: HashSets allow $O(1)$ lookups, while Sorted Two-Pointers work in $O(N \log N)$ total time.
Complexity:
  • Time: O(n + m) for HashSet | O(n log n) for Sorting.
  • Space: O(n + m) to store unique results and helper structures.
