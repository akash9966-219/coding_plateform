72. Edit Distance

Return the minimum operations (Insert, Delete, Replace) required to convert word1 to word2.
DP State Transitions:
If word1[i] == word2[j]:
  dp[i][j] = dp[i-1][j-1]
Else:
  dp[i][j] = 1 + min(
    dp[i-1][j], // Delete
    dp[i][j-1], // Insert
    dp[i-1][j-1] // Replace
  )
Complexity:
  • Time: O(m * n)
  • Space: O(m * n)
