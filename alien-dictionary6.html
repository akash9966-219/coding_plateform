269. Alien Dictionary

Description

There is a new alien language that uses the English alphabet. However, the order of the letters is unknown to you. You are given a list of strings words from the alien language's dictionary, where the strings are sorted lexicographically.

Return a string of the unique letters in the new alien language sorted in lexicographical increasing order. If there is no solution, return "".

Example
Input words = ["wrt","wrf","er","ett","rftt"]
Output "wertf"
