901. Online Stock Span

Design an algorithm that collects daily price quotes for a stock and returns the span of that stock's price for the current day.
Sample Test Case:
InputOutput
next(100), next(80), next(60), next(70), next(60), next(75), next(85)1, 1, 1, 2, 1, 4, 6
Monotonic Stack Logic:
Stack stores [price, span].

For price P:
  current_span = 1
  While stack.top().price <= P:
    current_span += stack.pop().span
  stack.push([P, current_span])
  Return current_span
Complexity:
  • Time: O(1) Amortized - Each price is pushed and popped exactly once.
  • Space: O(n) - To store the prices in the stack.
