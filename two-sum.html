1. Two Sum

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.
Example:
Input: nums = [2,7,11,15], target = 9
Output: [0,1] (2 + 7 = 9)
Hashing Logic:
1. Create a HashMap to store (value, index).
2. For each num at index i:
   a. Calculate diff = target - num.
   b. If diff is in Map, return [Map.get(diff), i].
   c. Otherwise, add num to Map.
Complexity:
  • Time: O(n) - Single pass through the array.
  • Space: O(n) - To store numbers in the hash table.
