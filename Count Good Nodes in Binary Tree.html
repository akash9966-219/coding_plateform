1448. Count Good Nodes

Given a binary tree root, a node X is named good if in the path from root to X there are no nodes with a value greater than X. Return the number of good nodes.
Sample Test Case:
Input (root) Good Nodes Total Count
[3, 1, 4, 3, null, 1, 5] 3, 4, 3, 5 4
DFS Logic:
countGood(node, maxVal):
  if node == NULL: return 0
  count = (node.val >= maxVal) ? 1 : 0
  newMax = max(maxVal, node.val)
  return count + countGood(node.left, newMax)
              + countGood(node.right, newMax)
Complexity:
  • Time: O(n) - Visit every node once.
  • Space: O(h) - Call stack depth equals tree height.
