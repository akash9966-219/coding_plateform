3. Longest Substring

Find the length of the longest substring without repeating characters.
Example 1:
Input: s = "abcabcbb"
Output: 3
Explanation: "abc" (length 3)
Logic:
1. Map: Store the last index of each character.
2. Pointers: Use left and right for a sliding window.
3. Jump: If duplicate found at index i, move left to i + 1.
4. Result: maxLength = max(maxLength, right - left + 1).
Complexity:
  • Time: O(n) - Single pass.
  • Space: O(min(m, n)) - Set/Map size (m is alphabet size).
