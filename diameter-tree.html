543. Tree Diameter

Return the length of the longest path between any two nodes in a tree. The length is the number of edges.
Visual Reference:
Bottom-Up DFS Logic:
1. left_h: Max depth of left subtree.
2. right_h: Max depth of right subtree.
3. local_diameter: left_h + right_h.
4. Update: max_diam = max(max_diam, local_diameter).
5. Return: 1 + max(left_h, right_h).
Complexity:
  • Time: O(n) - Single post-order traversal.
  • Space: O(h) - Recursive stack space.
