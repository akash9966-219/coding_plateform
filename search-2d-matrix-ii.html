240. Search a 2D Matrix II

Search for a target value in an m times n matrix where each row and column is sorted in ascending order.
Example 1:

Input: target = 5
Output: true
Logic:
1. Start: Begin at the top-right corner (row 0, last column).
2. Greater: If val > target, move left (the column is too large).
3. Smaller: If val < target, move down (the row is too small).
4. Boundaries: Stop if row or column goes out of bounds.
Complexity:
  • Time: O(m + n) - Maximum steps is total rows + cols.
  • Space: O(1) - Iterative search.
