1318. Minimum Flips OR

Given 3 positives a, b, and c. Return the minimum flips required in bits of a and b to make (a OR b == c).
Sample Test Case:
abcOutput
2 (010)6 (110)5 (101)3
Flipping Logic:
For each bit position:
- If c_bit == 1: Need (a_bit | b_bit) == 1. If both 0, +1 flip.
- If c_bit == 0: Need both a_bit and b_bit to be 0.
  If a_bit == 1, +1 flip.
  If b_bit == 1, +1 flip.
Complexity:
  • Time: O(1) - Iterates through 32 bits (constant).
  • Space: O(1) - Constant variables.
