646. Max Length Pair Chain

Description

You are given an array of n pairs pairs where pairs[i] = [left_i, right_i] and left_i < right_i.

A pair p2 = [c, d] follows a pair p1 = [a, b] if b < c. A chain of pairs can be formed in this fashion. Return the length of the longest chain which can be formed.

Example
Input pairs = [[1,2],[2,3],[3,4]]
Output 2
Explanation The longest chain is [1,2] -> [3,4].
