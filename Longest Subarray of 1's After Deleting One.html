1493. Longest Subarray

Given a binary array nums, you should delete one element from it. Return the size of the longest non-empty subarray containing only 1's in the resulting array.
Examples:
Example 1:
Input: nums = [1,1,0,1]
Output: 3
Explanation: After deleting the number at index 2, [1,1,1] contains 3 ones.
Example 2:
Input: nums = [0,1,1,1,0,1,1,0,1]
Output: 5
Logic:
1. Sliding Window: Expand right pointer and count zeros.
2. Constraint: If zeros > 1, shrink left until zeros == 1.
3. Subtraction: The length is right - left (not +1) because one element is always deleted.
Complexity:
  • Time: O(n) - Linear scan with two pointers.
  • Space: O(1) - Constant auxiliary space.
