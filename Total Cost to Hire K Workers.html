2462. Total Cost to Hire K Workers

Choose k workers. In each session, hire the worker with the lowest cost from either the first candidates or last candidates workers.
Sample Test Case:
costskcandidatesOutput
[17,12,10,2,7,2,11,20,8]3411
Dual-Heap Logic:
1. headHeap: PriorityQueue for first c workers.
2. tailHeap: PriorityQueue for last c workers.
3. In each step, poll min(headHeap.peek(), tailHeap.peek()).
4. Refill from middle until pointers meet.
Complexity:
  • Time: O((k + candidates) * log candidates)
  • Space: O(candidates)
