55. Jump Game

Determine if you can reach the last index from the first index, given maximum jump lengths at each position.
Examples:
Input: nums = [2,3,1,1,4]
Output: true
Input: nums = [3,2,1,0,4]
Output: false
Greedy Reach Logic:
1. reach: Initialize maxReach = 0.
2. Iterate: Traverse the array with index i.
3. Check: If i > maxReach, return false.
4. Update: maxReach = max(maxReach, i + nums[i]).
True if you finish the loop or reach the end.
Complexity:
  • Time: O(n) - Single linear pass.
  • Space: O(1) - Constant variables.
