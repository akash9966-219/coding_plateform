234. Palindrome List

Determine if a singly linked list is a palindrome. Optimize for O(n) time and O(1) space.
Example 1:

Input: head = [1,2,2,1]
Output: true
Logic (O(1) Space):
1. Find Mid: Use Slow & Fast pointers to reach middle.
2. Reverse: Reverse the second half of the list.
3. Compare: Walk from head and mid to check equality.
4. Result: If any value differs, return false.
Complexity:
  • Time: O(n) - One pass for mid, one for reverse, one for compare.
  • Space: O(1) - In-place manipulation.
