200. Number of Islands

Given an m x n binary grid representing a map of '1's (land) and '0's (water), return the number of islands.
Examples:
Input: grid = [["1","1","0"],["1","1","0"],["0","0","1"]]
Output: 2
DFS Logic:
1. Iterate through every cell (r, c).
2. If grid[r][c] == '1', increment count and call DFS.
3. In DFS, mark current cell as '0' to avoid re-visiting.
4. Recursively visit 4-directional neighbors.
Sink each island as you find it.
Complexity:
  • Time: O(m * n) - Each cell is visited once.
  • Space: O(m * n) - Worst-case recursion stack.
