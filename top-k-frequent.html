347. Top K Frequent

Given an integer array, return the k most frequent elements. Use Bucket Sort to achieve O(n).
Logic:
1. Count: Create a Frequency Map of all elements.
2. Bucket: Create an array of lists where index = frequency.
3. Iterate: Traverse buckets from back (highest frequency) to front.
Linear Time Solution!
Complexity:
  • Time: O(n)
  • Space: O(n)
