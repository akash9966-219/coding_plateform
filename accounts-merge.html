721. Accounts Merge

Description

Given a list of accounts where each element accounts[i] is a list of strings, the first element accounts[i][0] is a name, and the rest are emails.

Merge accounts belonging to the same person. Two accounts belong to the same person if there is some common email to both accounts.

Example
Input accounts = [["John","a@m.com","b@m.com"],["John","c@m.com"],["John","a@m.com","d@m.com"]]
Output [["John","a@m.com","b@m.com","d@m.com"],["John","c@m.com"]]
