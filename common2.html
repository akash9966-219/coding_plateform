1035. Uncrossed Lines

Description

You are given two integer arrays nums1 and nums2. We write the integers of nums1 and nums2 in the order they are given.

We may draw connecting lines: a line connects nums1[i] and nums2[j] such that nums1[i] == nums2[j] and the line does not intersect any other connecting line. Return the maximum number of connecting lines we can draw.

Example
Input nums1 = [1,4,2], nums2 = [1,2,4]
Output 2
Explanation We can draw 2 uncrossed lines as in LCS (1 with 1, and 2 with 2). We cannot connect 4 with 4 because it would cross the line connecting 2 with 2.
