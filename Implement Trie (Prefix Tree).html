208. Implement Trie

A Trie or prefix tree stores strings efficiently. Each node stores a character and pointers to next characters.
Example 1:
Trie trie = new Trie(); trie.insert("apple"); trie.search("apple"); // true trie.search("app"); // false trie.startsWith("app"); // true
Complexity:
Time: O(L) for all operations (L = word length).
Space: O(N * L) where N is number of words.
