114. Flatten Tree

Flatten a binary tree into a single right-skewed "linked list" following Pre-order Traversal.
Example Reference:
In-Place Strategy:
1. Find the rightmost node of the current left subtree.
2. Attach current.right to that rightmost node's right.
3. Move current.left to current.right.
4. Set current.left to null.
Complexity:
  • Time: O(n) - Each edge visited constant times.
  • Space: O(1) - No recursion or stack.
