51. N-Queens

Place n queens on an n x n board such that no two queens attack each other.
Visual Reference:

Fig 1. Possible solutions for N=4.

Backtracking Constraints:
1. Vertical: Column c must be unique.
2. Major Diagonal: r + c must be unique.
3. Minor Diagonal: r - c must be unique.
Complexity:
  • Time: O(N!) - Exponential growth.
  • Space: O(N2) - For the board and recursion.
