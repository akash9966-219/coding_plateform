1926. Nearest Exit in Maze

Description

You are given an m x n matrix maze with empty cells ('.') and walls ('+'). You are also given the entrance of the maze.

Return the fewest number of steps to the nearest exit, or -1 if no such path exists.

Example
Input maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]], entrance = [1,2]
Output 1
