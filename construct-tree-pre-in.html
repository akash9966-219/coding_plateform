105. Tree from Pre/In

Construct a binary tree given its preorder and inorder traversals.
Example Reference:
Recursive Logic:
1. Root: preorder[preIdx++]
2. Pivot: Find Root in inorder map.
3. Build Left: range [inStart, pivot - 1]
4. Build Right: range [pivot + 1, inEnd]
Complexity:
  • Time: O(n) - With Hash Map lookup.
  • Space: O(n) - For Hash Map and recursion.
