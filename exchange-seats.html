626. Exchange Seats

Table: Seat
Column NameType
idint
studentvarchar
id is the primary key. The sequence starts from 1 and increments continuously.
Problem Statement
Write a solution to swap the seat id of every two consecutive students. If the number of students is odd, the id of the last student is not swapped.

Return the result table ordered by id in ascending order.
Example 1 Input
idstudent
1Abbot
2Doris
3Emerson
4Green
5Jeames
Output:
idstudent
1Doris
2Abbot
3Green
4Emerson
5Jeames
Explanation:
- ID 1 swaps with ID 2.
- ID 3 swaps with ID 4.
- ID 5 is the last record and total count is odd (5), so it remains ID 5.
