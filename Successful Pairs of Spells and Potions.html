2300. Successful Pairs

Given arrays spells and potions and an integer success. A pair is successful if spell * potion >= success. Return an array where each element is the number of successful potions for that spell.
Sample Test Cases:
Spells Potions Success Output
[5, 1, 3] [1, 2, 3, 4, 5] 7 [4, 0, 3]
Binary Search Strategy:
1. Sort potions: [1, 2, 3, 4, 5]
2. For Spell 5: Need potion >= ceil(7/5) = 1.4
   Potions [2, 3, 4, 5] work. Count = 4.
3. For Spell 1: Need potion >= ceil(7/1) = 7
   No potions work. Count = 0.
Complexity:
  • Time: O(M log M + N log M) - M is potions, N is spells.
  • Space: O(log M) - Sorting space.
