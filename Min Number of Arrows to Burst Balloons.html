452. Burst Balloons

Find the minimum number of arrows that must be shot to burst all balloons. Balloons are represented by intervals [x_start, x_end].
Sample Test Case:
Input (points)Output
[[10,16],[2,8],[1,6],[7,12]]2
[[1,2],[3,4],[5,6],[7,8]]4
Greedy Logic:
1. Sort by END position.
2. Shoot first arrow at points[0].end.
3. For next balloon:
   If balloon.start > arrow_pos:
     Shoot new arrow at current balloon.end.
     Increment arrow_count.
Complexity:
  • Time: O(N log N) - Due to sorting.
  • Space: O(log N) - Space for sorting implementation.
