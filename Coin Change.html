322. Coin Change

Return the fewest number of coins needed to make up a given amount. If it's impossible, return -1.
DP State:

Target: Amount 11, Coins [1, 2, 5]

dp[0] = 0
dp[1] = dp[0] + 1 = 1
dp[2] = min(dp[1]+1, dp[0]+1) = 1
...
dp[11] = min(dp[10]+1, dp[9]+1, dp[6]+1) = 3
Complexity:
  • Time: O(amount * n)
  • Space: O(amount)
