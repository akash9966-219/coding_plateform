236. Lowest Common Ancestor

Find the lowest common ancestor (LCA) of two given nodes in a binary tree. The LCA is defined as the lowest node in the tree that has both nodes as descendants.
Sample Test Case:
Root Array p, q LCA
[3,5,1,6,2,0,8,null,null,7,4] 5, 1 3
Recursive Logic:
findLCA(node, p, q):
  if node is NULL or p or q: return node
  left = findLCA(node.left, p, q)
  right = findLCA(node.right, p, q)

  if left and right: return node // Split found
  return left != NULL ? left : right
Complexity:
  • Time: O(n) - Traverse nodes until p and q are found.
  • Space: O(h) - Call stack depth.
