112. Path Sum

Given the root of a binary tree and targetSum, return true if there is a root-to-leaf path such that the sum of values equals targetSum.
Example 1:
Input: root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22
Output: true
Constraints:
  • The number of nodes is in range [0, 5000].
  • -1000 <= targetSum <= 1000
