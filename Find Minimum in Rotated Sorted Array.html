153. Find Minimum in RSA

Find the minimum element in a rotated sorted array of unique integers in O(log n) time.
Binary Search Logic:

nums = [4, 5, 6, 7, 0, 1, 2]

4
5
6
7 (Mid)
0
1
2 (Right)

Since Mid (7) > Right (2), Min must be in the right half.

Complexity:
  • Time: O(log n)
  • Space: O(1)
