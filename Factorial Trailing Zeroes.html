172. Trailing Zeroes

Return the number of trailing zeroes in n!. The solution must run in logarithmic time.
Mathematical Logic:

Trailing Zero = (Factor of 2) × (Factor of 5)

n = 100
1. 100 / 5 = 20
2. 100 / 25 = 4
3. 100 / 125 = 0
Total: 20 + 4 = 24 zeroes
Complexity:
  • Time: O(log5 n)
  • Space: O(1)
