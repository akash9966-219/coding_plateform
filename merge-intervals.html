56. Merge Intervals

Given an array of intervals, merge all overlapping intervals into a single covering interval.
Example 1:
Input: [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]
Logic:
1. Sort: Sort intervals by start value.
2. Rolling Merge: Iterate through sorted intervals.
3. Check: If current start <= lastEnd, merge by setting lastEnd = max(lastEnd, currentEnd).
4. Result: Linear O(n) scan after O(n log n) sort.
Complexity:
  • Time: O(n log n) - Dominant by sorting.
  • Space: O(log n) or O(n) - Sorting workspace.
