528. Random Pick with Weight

Description

You are given a 0-indexed array of positive integers w where w[i] describes the weight of the ith index.

You need to implement the function pickIndex(), which randomly picks an index in the range [0, w.length - 1] and returns it. The probability of picking an index i is w[i] / sum(w).

Example
Input ["Solution","pickIndex"]
[[[1,3]],[]]
Output [null,1]

Probability: P(0)=1/4=25%, P(1)=3/4=75%.
