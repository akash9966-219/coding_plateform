637. Average of Levels

Return the average value of nodes on each level. Answers within 10-5 are accepted.
Example 1:
Input: root = [3,9,20,null,null,15,7]
Output: [3.00000, 14.50000, 11.00000]
Constraints:
  • Number of nodes in range [1, 10,000].
  • Node values are standard 32-bit integers.
