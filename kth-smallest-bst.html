230. Kth Smallest in BST

Find the kth smallest value (1-indexed) of all the values of the nodes in a Binary Search Tree.
Example Reference:
Sorted Traversal Logic:
1. An Inorder Traversal (L → Root → R) of a BST visits nodes in ascending order.
2. Iterate through the tree and keep a counter.
3. When counter reaches k, return the current node value.
Complexity:
  • Time: O(h + k) - Best case; O(n) - Worst case.
  • Space: O(h) - Stack space.
