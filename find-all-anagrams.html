438. Find All Anagrams

Return all start indices of p's anagrams in s.
Example 1:
Input: s = "cbaebabacd", p = "abc"
Output: [0,6]
Logic:
1. Frequency: Create a count array for p.
2. Window: Slide a window of size p.length across s.
3. Update: Add the new char, remove the old char, and compare counts.
4. Result: If counts match, add the current start index.
Complexity:
  • Time: O(n) - Single pass through string s.
  • Space: O(1) - Frequency array is constant size (26).
