13. Roman to Integer

Roman numerals are represented by seven different symbols: I, V, X, L, C, D, M.

Convert a given Roman numeral string to an integer by handling standard addition and the six subtraction instances (IV, IX, XL, XC, CD, CM).
Symbol Table:
I: 1, V: 5, X: 10, L: 50, C: 100, D: 500, M: 1000
Example 3:
Input: s = "MCMXCIV"
Output: 1994
Explanation: M = 1000, CM = 900, XC = 90, IV = 4.
