1275. Tic Tac Toe Winner

Description

Tic-tac-toe is played by two players A and B on a 3 x 3 grid. Player A always places 'X' characters, while player B always places 'O' characters. Characters are always placed into empty squares of the grid.

The game ends when there are three of the same characters in a row, column, or diagonal. If all squares are filled and no one wins, the game ends in a draw.

Given an array moves, return the winner ("A" or "B") if it exists, "Draw" if it's a draw, or "Pending" if the game is still ongoing.

Example 1
Input moves = [[0,0],[2,0],[1,1],[2,1],[2,2]]
Output "A"
Explanation "A" makes moves at (0,0), (1,1), (2,2) forming a diagonal.
