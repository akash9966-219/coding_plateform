374. Guess Number Higher/Lower

I pick a number from 1 to n. You have to guess which number I picked. Use the guess(num) API to find out if your guess is too high, too low, or correct.
Sample Test Cases:
Input (n) Pick (Target) Output
10 6 6
1 1 1
Binary Search Strategy:
Initial: low = 1, high = 10, pick = 6

1. mid = 5. guess(5) returns 1 (Higher).
2. low = mid + 1 = 6.
3. mid = 8. guess(8) returns -1 (Lower).
4. high = mid - 1 = 7.
5. mid = 6. guess(6) returns 0 (Match!).
Complexity:
  • Time: O(log n) - Search space is halved each step.
  • Space: O(1) - Constant space usage.
