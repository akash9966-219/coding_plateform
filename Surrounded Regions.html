130. Surrounded Regions

Replace all 'O's with 'X's if they are surrounded by 'X's. An 'O' is not surrounded if it is connected to the edge of the board.
Strategy:
1. DFS from all border 'O's to mark escapable regions.
2. Iterate through board: 'O' → 'X', 'Marked' → 'O'.
Constraints:
  • m, n <= 200
  • Board contains only 'X' and 'O'.
