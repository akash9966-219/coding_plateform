1268. Search Suggestions

Design a system that suggests at most three product names from products after each character of searchWord is typed. Suggested products should have a common prefix with searchWord.
Sample Test Case:
ProductsSearchWordOutput
["mobile","mouse","moneypot"]"mou"[["mobile","moneypot","mouse"], ["moneypot","mouse"], ["mouse"]]
Efficiency Logic:
1. Sort products lexicographically.
2. Use left/right pointers to find the range matching the current prefix.
3. For each character i in searchWord:
  Update pointers: while (prod[L][i] != c) L++;
  Collect min(3, R-L+1) products.
Complexity:
  • Time: O(N log N + M) - N is products count, M is searchWord length.
  • Space: O(N) - Sorting and output storage.
