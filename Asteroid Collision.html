735. Asteroid Collision

Find out the state of the asteroids after all collisions. If two asteroids meet, the smaller one explodes. If both are the same size, both explode. Asteroids moving in the same direction never meet.
Examples:
Example 1:
Input: asteroids = [5,10,-5]
Output: [5,10]
Explanation: The 10 and -5 collide; 10 wins.
Logic:
1. Push: Always push positive (right-moving) asteroids.
2. Collide: For negative (left-moving) ones, check the stack top.
3. Loop: While stack.top > 0 and abs(negative) > stack.top, pop the stack.
4. Equal: If abs(negative) == stack.top, pop and don't add the negative one.
5. Safe: If stack is empty or top is negative, push the negative one.
Complexity:
  • Time: O(n) - Each asteroid is pushed and popped at most once.
  • Space: O(n) - Worst case, all asteroids move in the same direction.
