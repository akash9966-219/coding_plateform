283. Move Zeroes

Move all zeroes to the end of the array while maintaining the relative order of non-zero elements. Perform this in-place.
Example 1:
Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
Logic:
1. Pointer: Maintain lastNonZero index.
2. Swap: Iterate and swap non-zero elements with the element at lastNonZero.
3. Minimal Ops: Each element is processed exactly once.
4. Result: Zeroes naturally accumulate at the end.
Complexity:
  • Time: O(n) - Linear scan.
  • Space: O(1) - Constant space approach.
