933. Number of Recent Calls

You have a RecentCounter class which counts the number of recent requests within a certain time frame. Implement ping(int t) which returns the number of requests that happened in the last 3000 milliseconds.
Examples:
Example 1:
Inputs: ["RecentCounter", "ping", "ping", "ping", "ping"]
Values: [[], [1], [100], [3001], [3002]]
Output: [null, 1, 2, 3, 3]
Logic:
1. Queue: Use a queue to store timestamps in increasing order.
2. Add: Every ping(t) adds t to the queue.
3. Trim: Remove all timestamps from the front that are less than t - 3000.
4. Result: The size of the queue is the answer.
Complexity:
  • Time: O(1) average - Each timestamp is added and removed exactly once.
  • Space: O(W) - Where W is the window size (max 3000 requests).
