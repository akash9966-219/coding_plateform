162. Find Peak Element

Find a peak element (greater than its neighbors) in O(log n) time. Multiple peaks may exist; returning any is valid.
Binary Search Intuition:

If nums[i] < nums[i+1], go Right. Else, go Left.

Peak found at the "local maximum" of the slope.

Complexity:
  • Time: O(log n)
  • Space: O(1)
