2140. Solving Questions...

Description

You are given a 2D integer array questions where questions[i] = [points_i, brainpower_i].

If you solve question i, you get points_i points but you cannot solve any of the next brainpower_i questions. If you skip it, you get 0 points and move to the next.

Example
Input questions = [[3,2],[4,3],[4,4],[2,5]]
Output 5
Explanation Solve Q0 (3 pts), skip Q1 and Q2, solve Q3 (2 pts). Total: 5.
