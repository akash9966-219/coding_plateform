64. Min Path Sum

Find a path from top-left to bottom-right in an m x n grid that minimizes the sum of all numbers.
Visual Reference:

Optimal Path: 1 → 3 → 1 → 1 → 1 = 7

DP Relation:
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
Complexity:
  • Time: O(m * n)
  • Space: O(n) (can be optimized to use one row)
