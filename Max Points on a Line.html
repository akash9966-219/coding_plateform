149. Max Points on Line

Given an array of points, return the maximum number of points that lie on the same straight line.
Visual Reference:

Fig 1. Points [1,1], [2,2], and [3,3] are collinear.

Mathematical Logic:
  • Fix an anchor point i.
  • Calculate slope to every other point j.
  • Use GCD(dy, dx) to represent slope as a fraction string to avoid floating point errors.
