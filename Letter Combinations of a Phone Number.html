17. Letter Combinations

Given a string of digits 2-9, return all possible letter combinations the number could represent based on a phone keypad.
Example 1:
Input: digits = "23"
Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]
Complexity:
  • Time: O(4N), where N is number of digits.
  • Space: O(N) for the recursion stack.
