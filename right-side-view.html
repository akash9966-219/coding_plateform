199. Right Side View

Imagine yourself standing on the right side of the tree. Return the values of the nodes you can see from top to bottom.
Visual Reference:
BFS Logic:
1. Use a Queue for Level Order Traversal.
2. For each level, iterate through all its nodes.
3. The last node of each level is visible from the right side.
4. Append that node's value to the result.
Complexity:
  • Time: O(n) - Traverse every node once.
  • Space: O(w) - Width of the tree (max nodes at one level).
