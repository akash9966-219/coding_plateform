207. Course Schedule

Determine if you can finish all courses given prerequisite pairs. This is equivalent to checking if the directed graph has a cycle.
Examples:
Input: numCourses = 2, prerequisites = [[1,0]]
Output: true
Input: numCourses = 2, prerequisites = [[1,0],[0,1]]
Output: false
BFS Logic (Kahn's):
1. Indegree: Count prerequisites for each course.
2. Queue: Add courses with 0 prerequisites.
3. BFS: Pop course, decrement indegree of its dependents.
4. Cycle Check: If total courses popped equals numCourses, return true.
Complexity:
  • Time: O(V + E) - Visit every node and edge.
  • Space: O(V + E) - Adjacency list storage.
