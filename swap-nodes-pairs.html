24. Swap Nodes in Pairs

Swap every two adjacent nodes in a linked list. You must physically move the nodes, not just change their values.
Example 1:

Input: head = [1,2,3,4]
Output: [2,1,4,3]
Logic:
1. Dummy: Create dummy node pointing to head.
2. Pairing: Identify first = prev.next and second = first.next.
3. Swap: Point first.next to second.next, then second.next to first.
4. Link: Point prev.next to second.
Complexity:
  • Time: O(N) - One pass.
  • Space: O(1) - Constant space.
