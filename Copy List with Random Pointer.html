138. Copy List with Random Pointer

Construct a deep copy of a linked list where each node contains an additional random pointer.

The deep copy must consist of exactly n brand new nodes. None of the pointers in the new list should point to nodes in the original list.
Example 1:
Input: head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
Output: [[7,null],[13,0],[11,4],[10,2],[1,0]]
Constraints:
  • 0 <= n <= 1000
  • -104 <= Node.val <= 104
  • Node.random is null or pointing to a node in the list.
