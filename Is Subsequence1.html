392. Is Subsequence

Given two strings s and t, return true if s is a subsequence of t, or false otherwise.
Examples:
Example 1:
Input: s = "abc", t = "ahbgdc"
Output: true
Example 2:
Input: s = "axc", t = "ahbgdc"
Output: false
Logic:
1. Two Pointers: Initialize i = 0 (for s) and j = 0 (for t).
2. Match: While i < s.length and j < t.length, if s[i] == t[j], increment i.
3. Advance: Always increment j in every step to scan through t.
4. Result: If i == s.length, all characters were found in order.
Complexity:
  • Time: O(t.length) - Linear scan of the target string.
  • Space: O(1) - Constant space for pointers.
