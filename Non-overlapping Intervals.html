435. Non-overlapping Intervals

Given an array of intervals intervals where intervals[i] = [starti, endi], return the minimum number of intervals you need to remove to make the rest of the intervals non-overlapping.
Sample Test Case:
InputOutput
[[1,2],[2,3],[3,4],[1,3]]1
[[1,2],[1,2],[1,2]]2
Greedy Logic:
1. Sort intervals by END TIME.
2. Keep the interval that finishes earliest.
3. If next_interval.start < current_end:
   Overlap detected! Increment removal count.
4. Else:
   Update current_end = next_interval.end.
Complexity:
  • Time: O(N log N) - Sorting takes precedence.
  • Space: O(log N) or O(1) - Sorting space complexity.
