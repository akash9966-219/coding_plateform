216. Combination Sum III

Find all valid combinations of k numbers that sum up to n such that only numbers from 1 to 9 are used and each number is used at most once.
Sample Test Case:
knOutput
37[[1,2,4]]
39[[1,2,6],[1,3,5],[2,3,4]]
Backtracking Logic:
solve(start, k, n, path):
  if k == 0 and n == 0:
    result.add(path); return
  if k == 0 or n < 0:
    return

  for i from start to 9:
    path.add(i)
    solve(i + 1, k - 1, n - i, path)
    path.pop() // Backtrack
Complexity:
  • Time: $O(\binom{9}{k})$ - Choosing $k$ numbers from 9.
  • Space: $O(k)$ - Max recursion depth.
