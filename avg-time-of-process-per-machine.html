1661. Average Time of Process per Machine

Table: Activity
Column NameType
machine_idint
process_idint
activity_typeenum ('start', 'end')
timestampfloat
(machine_id, process_id, activity_type) is the primary key.
Each process has exactly one 'start' and one 'end' timestamp.
Problem Statement
Find the average time each machine takes to complete a process.
Time = 'end' timestamp - 'start' timestamp.
Result should be rounded to 3 decimal places.
Example 1:

Input: Activity Table

machine_idprocess_idactivity_typetimestamp
00start0.712
00end1.520
10start0.550
10end1.550

Output:

machine_idprocessing_time
00.894
10.995
Explanation:
For machine 0: ((1.520 - 0.712) + ...) / total_processes = 0.894.
