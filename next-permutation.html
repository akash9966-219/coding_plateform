31. Next Permutation

Implement next permutation, which rearranges numbers into the lexicographically next greater permutation of numbers. If not possible, return the lowest order.
Logic:
1. Pivot: Find first nums[i] < nums[i+1] from right.
2. Successor: Find first nums[j] > nums[i] from right.
3. Swap: Swap nums[i] and nums[j].
4. Reverse: Reverse everything after index i to get the smallest suffix.
Complexity:
  • Time: O(n) - Linear scan and reversal.
  • Space: O(1) - Constant space approach.
