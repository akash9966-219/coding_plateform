4. Median Sorted Arrays

Find the median of two sorted arrays in O(log(m+n)). This requires binary search on the partitioning index.
Partition Logic:

Target: LeftPart.size == RightPart.size

Array1: [ ... L1 | R1 ... ]
Array2: [ ... L2 | R2 ... ]
Condition: L1 <= R2 && L2 <= R1
Complexity:
  • Time: O(log(min(m, n)))
  • Space: O(1)
