300. Longest Increasing Subsequence

Find the length of the longest strictly increasing subsequence. Can you do it in O(n log n)?
Optimized Binary Search Logic:

Tails Array Maintenance

nums: [10, 9, 2, 5, 3, 7]
1. [10]

4. [2, 5]
5. [2, 3] (replaced 5)
6. [2, 3, 7] → Length: 3
Complexity:
  • Time: O(n log n)
  • Space: O(n)
