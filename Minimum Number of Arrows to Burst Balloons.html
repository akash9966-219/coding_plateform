452. Burst Balloons Arrows

Balloons are represented as 2D intervals [xstart, xend]. An arrow shot at x bursts any balloon where xstart <= x <= xend.

Return the minimum number of arrows to burst all balloons.
Example 1:
Input: points = [[10,16],[2,8],[1,6],[7,12]]
Output: 2
Explanation: One arrow at x=6 (bursts [2,8],[1,6]) and one at x=12 (bursts [10,16],[7,12]).
Constraints:
  • 1 <= points.length <= 105
  • -231 <= xstart < xend <= 231 - 1
