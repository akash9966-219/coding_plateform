76. Minimum Window

Find the minimum substring of s that contains all characters of t.
Example 1:
Input: s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"
Logic:
1. Maps: Count frequencies in t.
2. Expand: Move right pointer until window is valid.
3. Contract: Move left pointer to minimize window length.
4. Record: Store the smallest valid substring found.
Complexity:
  • Time: O(m + n) - Each character is visited at most twice.
  • Space: O(k) - Frequency map size (max 52 for letters).
