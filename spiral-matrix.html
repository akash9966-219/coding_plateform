54. Spiral Matrix

Return all elements of an $m \times n$ matrix in spiral order.
Example 1:

Input: [[1,2,3],[4,5,6],[7,8,9]]
Output: [1,2,3,6,9,8,7,4,5]
Logic:
1. Boundaries: Define top, bottom, left, right.
2. Movement: Traverse Right → Down → Left → Up.
3. Contraction: Shrink the boundary after completing each side.
4. Check: Ensure row/column still exists before reversing direction.
Complexity:
  • Time: O(m * n) - Visit every element exactly once.
  • Space: O(1) - (Output list not counted).
