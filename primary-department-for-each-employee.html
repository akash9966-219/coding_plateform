1789. Primary Department for Each Employee

Table: Employee
Column NameType
employee_idint
department_idint
primary_flagenum
(employee_id, department_id) is the primary key.
If primary_flag = 'Y', it is the primary department.
If an employee has only one row, that department is primary (even if flag is 'N').
Problem Statement
Report all employees with their primary department. For employees who belong to only one department, report that single department.
Example 1 Input
employee_iddept_idflag
11N
21Y
22N
33N
Output:
employee_iddepartment_id
11
21
33
Explanation:
Employee 1 has only one dept, so we pick it.
Employee 2 has multiple, so we pick the one marked 'Y'.
