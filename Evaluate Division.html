399. Evaluate Division

Given equations A / B = val, solve queries C / D = ?. Represent the variables as nodes in a graph and the values as edge weights.
Core Logic:
Map each string to an integer ID. Build an adjacency matrix/list where adj[u][v] = val and adj[v][u] = 1.0/val. Use DFS for each query.
Constraints:
  • Equations length <= 20
  • Variable strings length <= 5
  • No division by zero.
