450. Delete Node in a BST

Given a root node reference of a BST and a key, delete the node with the given key in the BST. Return the root node reference (possibly updated) of the BST.
Sample Test Cases:
Input (root)KeyOutput
[5,3,6,2,4,null,7]3[5,4,6,2,null,null,7]
Deletion Logic:
if key < root.val: root.left = delete(root.left, key)
else if key > root.val: root.right = delete(root.right, key)
else:
  if no children: return null
  if one child: return child
  if two children:
    1. find min in right subtree
    2. root.val = min.val
    3. delete(root.right, min.val)
Complexity:
  • Time: O(h) - Where h is height of tree.
  • Space: O(h) - Recursive stack space.
