66. Plus One

Increment a large integer (represented as an array of digits) by one.
Edge Case Logic:

Input: [9, 9, 9]

1. digits[2] becomes 0, carry 1
2. digits[1] becomes 0, carry 1
3. digits[0] becomes 0, carry 1
4. Result: [1, 0, 0, 0]
Complexity:
  • Time: O(n)
  • Space: O(n) - in the worst case where all digits are 9.
