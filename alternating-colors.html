1129. Alternating Colors

Description

You are given n nodes and two types of edges: redEdges and blueEdges.

Find the shortest path from node 0 to every node such that the edges in the path alternate in color.

Example
Input n = 3, red_edges = [[0,1]], blue_edges = [[1,2]]
Output [0,1,2]
