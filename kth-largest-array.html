215. Kth Largest

Find the kth largest element in an array without sorting. Note that it is the kth largest in sorted order, not distinct.
Logic:
1. Min-Heap: Use a heap to store the $k$ largest elements.
2. Maintenance: If heap size > $k$, pop the smallest (top).
3. Result: The root of the heap is the $k^{th}$ largest.
Time Complexity: $O(n \log k)$.
Complexity:
  • Time: O(n log k)
  • Space: O(k) - Heap size.
