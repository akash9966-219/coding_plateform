39. Combination Sum

Find all unique combinations in candidates where the chosen numbers sum up to target. Numbers can be reused.
Backtracking logic:
For each candidate:
1. Pick: target ← target - val, keep index
2. Skip: target stays same, index ← index + 1
Base Case: target == 0
Complexity:
  • Time: O(2target) - Worst case exponential.
  • Space: O(target/min_val) - Depth of recursion.
