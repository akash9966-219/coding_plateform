9. Palindrome Number

Determine whether an integer is a palindrome. An integer is a palindrome when it reads the same backward as forward.
Mathematical Logic:

Target: x = 1221

1. x = 1221, reversed = 0
2. x = 122, reversed = 1
3. x = 12, reversed = 12
Match: x == reversed
Follow-up: No Strings
By reversing only half the number, we avoid overflow and satisfy the string conversion constraint.
