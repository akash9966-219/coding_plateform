1533. Find Index of Large Integer

Description

We have an array of integers arr, where all elements are equal except for one which is larger.

You have a ArrayReader object with a function compareSub(l1, r1, l2, r2) that compares the sums of two sub-arrays.

Return the index of the larger integer.

Example
Input arr = [7,7,7,7,10,7,7,7]
Output 4
