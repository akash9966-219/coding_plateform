34. First/Last Pos

Find the starting and ending position of target in a sorted array. Required Complexity: O(log n).
Dual Search Strategy:
1. Search First: If nums[mid] == target, move high left.
2. Search Last: If nums[mid] == target, move low right.
O(log n) + O(log n) = O(log n)
Complexity:
  • Time: O(log n)
  • Space: O(1)
