338. Counting Bits

Given an integer n, return an array ans of length n + 1 such that for each i (0 <= i <= n), ans[i] is the number of 1's in the binary representation of i.
Sample Test Case:
nOutput
2[0, 1, 1]
5[0, 1, 1, 2, 1, 2]
DP Logic:
ans[i] = ans[i >> 1] + (i & 1)

Example i=5 (101):
i >> 1 is 2 (010). ans[2] = 1.
i & 1 is 1.
ans[5] = 1 + 1 = 2.
Complexity:
  • Time: O(n) - Single pass from 0 to n.
  • Space: O(1) - Excluding the output array.
