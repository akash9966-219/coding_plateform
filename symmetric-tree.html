101. Symmetric Tree

Check whether a binary tree is a mirror of itself.
Example Reference:
Mirror Logic:
To be symmetric at node A and B:
1. A.val == B.val
2. Mirror 1: A.left == B.right
3. Mirror 2: A.right == B.left
Complexity:
  • Time: O(n) - One full traversal.
  • Space: O(h) - Tree height.
