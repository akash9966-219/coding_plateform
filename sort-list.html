148. Sort List

Sort a linked list in ascending order using Merge Sort to ensure $O(n \log n)$ time complexity.
Example 1:

Input: head = [4,2,1,3]
Output: [1,2,3,4]
Logic:
1. Divide: Find the middle node using Slow & Fast pointers and split the list.
2. Recurse: Sort the left and right halves independently.
3. Merge: Combine the two sorted halves into a single sorted list.
O(n log n) Time | O(log n) Space.
Complexity:
  • Time: O(n log n)
  • Space: O(log n) - Stack depth.
