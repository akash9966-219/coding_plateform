79. Word Search

Given an m x n grid and a word, return true if the word exists in the grid using adjacent cells.
Visual Reference:
DFS Logic:
1. Mark: tmp = board[r][c]; board[r][c] = '#'
2. Explore: Up, Down, Left, Right
3. Unmark: board[r][c] = tmp (Backtrack)
Complexity:
  • Time: O(N * 3L) - N cells, L word length.
  • Space: O(L) - Recursion depth.
