602. Friend Requests II: Who Has the Most Friends

Table: RequestAccepted
Column NameType
requester_idint
accepter_idint
accept_datedate
(requester_id, accepter_id) is the primary key.
A friendship exists if an ID appears in either column.
Problem Statement
Find the people who have the most friends and the number of friends they have.

Note: There will only be one person with the maximum number of friends in the provided test cases.
Example 1 Input
requester_idaccepter_id
12
13
23
34
Output:
idnum
33
Explanation:
- ID 1 is friends with 2 and 3 (Total: 2).
- ID 2 is friends with 1 and 3 (Total: 2).
- ID 3 is friends with 1, 2, and 4 (Total: 3).
- ID 4 is friends with 3 (Total: 1).
