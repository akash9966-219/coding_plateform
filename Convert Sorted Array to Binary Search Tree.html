108. Sorted Array to BST

Convert an ascending sorted array into a height-balanced binary search tree. A height-balanced tree is one where the depth of the two subtrees of every node never differs by more than 1.
Example:
Input: nums = [-10, -3, 0, 5, 9]
Output: [0, -3, 9, -10, null, 5]
Constraints:
  • 1 ≤ nums.length ≤ 104
  • Array is strictly increasing.
