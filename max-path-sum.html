124. Max Path Sum

Find the maximum path sum of any non-empty path in a binary tree. Paths do not have to pass through the root.
Example Reference:
DFS Strategy:
1. LeftGain: max(0, dfs(left))
2. RightGain: max(0, dfs(right))
3. CurrentPath: node.val + LeftGain + RightGain
4. Return to Parent: node.val + max(LeftGain, RightGain)
Complexity:
  • Time: O(n) - One pass.
  • Space: O(h) - Tree height.
