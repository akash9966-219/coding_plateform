74. Search a 2D Matrix

Find the target in an m x n matrix where rows are sorted and the first element of a row is greater than the last element of the previous row.
Matrix Representation:
The "Flat" Logic:
Total elements: m * n
Virtual 1D mid → Matrix [mid / n][mid % n]
Constraints:
  • Time: O(log(m * n))
  • Space: O(1)
