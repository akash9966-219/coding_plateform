1926. Nearest Exit from Maze

Find the nearest exit from a '.' in a maze starting at entrance. An exit is defined as an empty cell that is at the border of the maze. The entrance does not count as an exit.
Sample Test Case:
MazeEntranceOutput
[["+","+",".","+"],[".",".",".","+"],["+","+","+","."]][1, 2]1
BFS Logic:
1. Queue q = [[start_row, start_col, 0]]
2. Mark entrance as visited ('+')
3. while q:
   curr = q.pop()
   for next_step in 4_directions:
     if border and empty: return steps + 1
     if empty: add to q and mark visited
Complexity:
  • Time: O(M * N) - Visit each cell at most once.
  • Space: O(M * N) - Queue storage.
