62. Unique Paths

Find the number of unique paths a robot can take from the top-left to the bottom-right of an m x n grid moving only right or down.
Example:
Input: m = 3, n = 7
Output: 28
Visual Reference:
DP Logic:
1. Initialize: Row with all 1s.
2. Iterate: Through each row and column.
3. Sum: New cell = top + left.
Target: dp[m-1][n-1]
Complexity:
  • Time: O(m * n)
  • Space: O(n) - Optimized 1D array.
