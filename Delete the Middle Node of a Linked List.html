2095. Delete Middle Node

You are given the head of a linked list. Delete the middle node, and return the head of the modified linked list.
Examples:
Example 1:
Input: head = [1,3,4,7,1,2,6]
Output: [1,3,4,1,2,6]
Explanation: The middle node is 7 at index 3.
Logic:
1. Two Pointers: Use slow and fast pointers.
2. Search: Move fast twice as fast as slow.
3. Target: To delete, we need the node before the middle. We start fast at head.next.next.
4. Delete: slow.next = slow.next.next.
Complexity:
  • Time: O(n) - Single pass through the list.
  • Space: O(1) - Constant auxiliary space.
