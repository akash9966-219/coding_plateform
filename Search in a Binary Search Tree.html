700. Search in a BST

Find the node in the Binary Search Tree (BST) that the node's value equals val and return the subtree rooted with that node. If such a node does not exist, return null.
Sample Test Cases:
Input (root) Target (val) Output (subtree)
[4, 2, 7, 1, 3] 2 [2, 1, 3]
[4, 2, 7, 1, 3] 5 [] (null)
BST Property Logic:
Searching for 2 in tree [4, 2, 7, 1, 3]:

1. Root is 4. (2 < 4) -> Go Left.
2. Current is 2. (2 == 2) -> Match Found!
3. Return node with subtree [2, 1, 3].
Complexity:
  • Time: O(log n) - Balanced / O(n) - Skewed
  • Space: O(h) - Recursive call stack depth.
