11. Container With Most Water

You are given an integer array height of length n. Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return the maximum amount of water a container can store.
Example 1:
Input: height = [1,8,6,2,5,4,8,3,7] Output: 49 Explanation: Max area is between index 1 and 8. Width = 7, Height = min(8, 7) = 7. Area = 7 * 7 = 49.
Constraints:
  • n == height.length
  • 2 <= n <= 105
  • 0 <= height[i] <= 104
