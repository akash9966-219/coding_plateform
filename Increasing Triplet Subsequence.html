334. Increasing Triplet

Return true if there exists a triple of indices (i, j, k) such that i < j < k and nums[i] < nums[j] < nums[k].
Examples:
Example 1:
Input: nums = [1,2,3,4,5]
Output: true
Example 3:
Input: nums = [2,1,5,0,4,6]
Output: true
Logic:
1. Smallest: Use first to store the smallest value seen.
2. Mid: Use second to store the second smallest value seen.
3. Greedy: For each number, try updating first first, then second.
4. Win: If a number exceeds both, a triplet exists.
Complexity:
  • Time: O(n) - Single pass.
  • Space: O(1) - Two variables only.
