1679. Max K-Sum Pairs

Find the maximum number of operations you can perform on an array. In one operation, you can pick two numbers from the array whose sum equals k and remove them.
Examples:
Example 1:
Input: nums = [1,2,3,4], k = 5
Output: 2
Explanation: Pair (1,4) and (2,3) both sum to 5.
Logic:
1. Sort: Sort the array to use two-pointer logic.
2. Initialize: left = 0, right = n - 1.
3. Check Sum:
- If sum == k: count++, move both inward.
- If sum < k: move left++.
- If sum > k: move right--.
Complexity:
  • Time: O(n log n) - Due to sorting the array.
  • Space: O(1) or O(log n) - Depending on sorting implementation.
