399. Evaluate Division

Given equations a / b = k, evaluate queries c / d = ?. Return the results as an array. If a path cannot be determined, return -1.0.
Sample Test Case:
EquationsValuesQueriesOutput
[["a","b"],["b","c"]][2.0, 3.0][["a","c"]][6.0]
Graph Strategy:
1. Nodes: variables (a, b, c).
2. Edges: (a -> b) weight 2.0, (b -> a) weight 0.5.
3. Query (a / c):
   Find path a -> b -> c.
   Result = (a->b) * (b->c) = 2.0 * 3.0 = 6.0.
Complexity:
  • Time: O(Q * (V + E)) - BFS/DFS or O(V³) - Floyd-Warshall.
  • Space: O(V + E) - Adjacency map or Matrix.
