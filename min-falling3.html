931. Min Falling Path Sum

Description

Given an n x n array of integers matrix, return the minimum sum of any falling path through the matrix.

A falling path starts at any element in the first row and chooses the element in the next row that is either directly below it or diagonally left/right.

Example
Input matrix = [[2,1,3],[6,5,4],[7,8,9]]
Output 13
Explanation Possible paths: 1→4→8 (13), 1→5→7 (13).
