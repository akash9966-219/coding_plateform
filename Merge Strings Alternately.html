1768. Merge Strings Alternately

Merge two strings by adding letters in alternating order, starting with word1. If a string is longer, append the extra letters at the end.
Logic:
1. Loop: Iterate while index i < max(len1, len2).
2. Word 1: If i < len1, add word1[i] to result.
3. Word 2: If i < len2, add word2[i] to result.
4. Result: Return the combined string.
Complexity:
  • Time: O(m + n) - We visit every character once.
  • Space: O(m + n) - To store the resulting merged string.
