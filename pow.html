50. Pow(x, n)

Description

Implement pow(x, n), which calculates x raised to the power n (i.e., xn).

Mathematical Logic
- If n is negative: x^n = (1/x)^(-n)
- If n is even: x^n = (x^2)^(n/2)
- If n is odd: x^n = x * (x^2)^((n-1)/2)
Valid Test Cases
Input x = 2.00000, n = 10
Output 1024.00000
