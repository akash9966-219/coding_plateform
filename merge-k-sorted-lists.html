23. Merge k Sorted Lists

Merge $k$ sorted linked lists into one single sorted linked list. This is solved efficiently using a Min-Heap.
Logic:
1. Initialize: Push the first node of each list into a Min-Heap.
2. Process: Pop the smallest node, attach it to the result list.
3. Advance: If the popped node has a next, push it to the heap.
Complexity: $O(N \log k)$ where $N$ is total nodes.
Complexity:
  • Time: O(N log k)
  • Space: O(k)
