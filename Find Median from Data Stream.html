295. Median Data Stream

Return the median of all elements added so far. If total elements are even, return the mean of the two middle values.
Heap Balancing Rules:

Two Heaps must stay balanced within size 1.

1. addNum(x): Push to Max-Heap (Left)
2. Max-Heap.top → Min-Heap (Right)
3. If Right > Left: Min-Heap.top → Max-Heap
Complexity:
  • addNum: O(log n)
  • findMedian: O(1)
  • Space: O(n)
