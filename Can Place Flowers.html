605. Can Place Flowers

Given a flowerbed where 1 means planted and 0 means empty, determine if n new flowers can be planted without any two being adjacent.
Examples:
Example 1:
Input: flowerbed = [1,0,0,0,1], n = 1
Output: true
Example 2:
Input: flowerbed = [1,0,0,0,1], n = 2
Output: false
Logic:
1. Greedy: Iterate through the array and plant a flower wherever valid.
2. Validation: A spot is valid if it's 0 AND its left neighbor is 0 (or start) AND its right neighbor is 0 (or end).
3. Update: When planting, set flowerbed[i] = 1 and decrement n.
4. Result: Return true if n <= 0 at any point.
Complexity:
  • Time: O(m) - Linear scan of the flowerbed.
  • Space: O(1) - Constant auxiliary space.
