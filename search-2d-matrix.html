74. Search a 2D Matrix

Determine if target exists in an m x n matrix where rows and columns are globally sorted. Complexity: O(log(m * n)).
Visual Reference:
Index Mapping:
Virtual Index mid → Matrix Coordinates:
row = mid / cols
col = mid % cols
Complexity:
  • Time: O(log(m * n))
  • Space: O(1)
