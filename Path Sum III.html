437. Path Sum III

Given the root of a binary tree and an integer targetSum, return the number of paths where the sum of the values along the path equals targetSum. The path does not need to start at the root or end at a leaf.
Sample Test Case:
Root Array Target Sum Total Paths
[10,5,-3,3,2,null,11,3,-2,null,1] 8 3
Prefix Sum Logic:
1. currSum += node.val
2. count += prefixMap[currSum - target]
3. prefixMap[currSum]++
4. dfs(left), dfs(right)
5. prefixMap[currSum]-- (Backtrack)
Complexity:
  • Time: O(n) - Linear traversal with O(1) map operations.
  • Space: O(n) - Hash map storage and call stack depth.
