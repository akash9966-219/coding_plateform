208. Implement Trie

Implement the Trie class:
  • insert(word): Inserts the string into the trie.
  • search(word): Returns true if the string is in the trie.
  • startsWith(prefix): Returns true if there is a previously inserted string that has the prefix.
Sample Test Case:
MethodArgumentReturn
insert"apple"null
search"apple"true
search"app"false
startsWith"app"true
Structure Logic:
Node {
  Node[26] children;
  boolean isEndOfWord;
}

1. Root is empty.
2. 'a' points to Node for 'a'.
3. Node 'e' in "apple" has isEndOfWord = true.
Complexity:
  • Time: O(L) - L is the length of word/prefix per operation.
  • Space: O(ALPHABET_SIZE * N * L) - Total characters stored.
