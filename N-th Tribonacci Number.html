1137. N-th Tribonacci Number

The Tribonacci sequence T_n is defined as: T_0 = 0, T_1 = 1, T_2 = 1, and T_{n+3} = T_n + T_{n+1} + T_{n+2} for n \ge 0. Given n, return the value of T_n.
Sample Test Cases:

251389537
DP Logic (Space Optimized):
Initial: a=0, b=1, c=1

for i from 3 to n:
  sum = a + b + c
  a = b
  b = c
  c = sum

return c
Complexity:
  • Time: $O(n)$ - Single pass through $n$.
  • Space: $O(1)$ - Only using 3 variables.
