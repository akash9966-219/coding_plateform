322. Coin Change

Find the fewest number of coins needed to make up a total amount. Return -1 if it's impossible.
Examples:
Input: coins = [1,2,5], amount = 11
Output: 3 (5 + 5 + 1)
Input: coins = [2], amount = 3
Output: -1
DP Relation:
1. Initialize: dp[0] = 0, others to amount + 1.
2. Outer: Loop through amount 1 to target.
3. Inner: Loop through each coin.
4. Update: dp[i] = min(dp[i], dp[i - coin] + 1).
Complexity:
  • Time: O(amount * n) - n is number of coins.
  • Space: O(amount)
