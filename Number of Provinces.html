547. Number of Provinces

There are n cities. Some of them are connected, while some are not. A province is a group of directly or indirectly connected cities and no other cities outside of the group.
Sample Test Cases:
Input (isConnected)Output
[[1,1,0],[1,1,0],[0,0,1]]2
[[1,0,0],[0,1,0],[0,0,1]]3
DFS Logic:
visited = [false] * n, count = 0

for i from 0 to n-1:
  if not visited[i]:
    count++
    dfs(i)

dfs(i):
  visited[i] = true
  for j from 0 to n-1:
    if isConnected[i][j] == 1 and not visited[j]:
      dfs(j)
Complexity:
  • Time: $O(n^2)$ - We traverse the entire $n \times n$ matrix.
  • Space: $O(n)$ - Size of the visited array.
