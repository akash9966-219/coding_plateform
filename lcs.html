1143. LCS

Given two strings, return the length of their longest common subsequence. If none exist, return 0.
Examples:
Input: text1 = "abcde", text2 = "ace"
Output: 3 ("ace")
Input: text1 = "abc", text2 = "def"
Output: 0
DP Relation:
1. Initialize: 2D array dp[m+1][n+1] with 0.
2. Match: If s1[i] == s2[j]: 1 + dp[i-1][j-1].
3. Mismatch: max(dp[i-1][j], dp[i][j-1]).
Final Answer: dp[m][n]
Complexity:
  • Time: O(m * n)
  • Space: O(m * n)
