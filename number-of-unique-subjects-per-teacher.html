2356. Number of Unique Subjects Taught by Each Teacher

Table: Teacher
Column NameType
teacher_idint
subject_idint
dept_idint
(subject_id, dept_id) is the primary key.
Each row indicates that a teacher teaches a specific subject in a specific department.
Problem Statement
Calculate the number of unique subjects each teacher teaches in the university. Return the result table in any order.
Example 1 Input
teacher_idsubject_iddept_id
123
124
133
211
221
Output:
teacher_idcnt
12
24
Explanation:
Teacher 1 teaches subject 2 (in depts 3 & 4) and subject 3. Total unique subjects = 2.
Teacher 2 teaches subjects 1, 2, 3, and 4. Total unique subjects = 4.
