215. Kth Largest Element

Find the kth largest element in an array without full sorting.
Example 1:
Input: nums = [3,2,1,5,6,4], k = 2
Output: 5
Heap Strategy Logic:
1. Create a Min-Heap of size k.
2. For each number:
   - Push to heap.
   - If size > k, pop the smallest.
3. The root of the heap is the answer.
Constraints:
  • 1 ≤ k ≤ nums.length ≤ 105
  • -104 ≤ nums[i] ≤ 104
