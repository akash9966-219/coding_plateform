239. Sliding Window Max

Return the maximum element for every sliding window of size k. Optimize for O(n) time complexity.
Logic:
1. Deque: Store indices of elements in decreasing order of values.
2. Pop Back: Remove indices if their value is <= nums[i].
3. Pop Front: Remove indices if they are outside the window (i - k).
4. Result: nums[deque.front()] is the current window maximum.
Complexity:
  • Time: O(n) - Every index is pushed and popped exactly once.
  • Space: O(k) - Deque stores at most k elements.
