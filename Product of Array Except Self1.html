238. Product Except Self

Given an integer array nums, return an array answer such that answer[i] is the product of all elements except nums[i]. Division is not allowed.
Examples:
Example 1:
Input: nums = [1,2,3,4]
Output: [24,12,8,6]
Example 2:
Input: nums = [-1,1,0,-3,3]
Output: [0,0,9,0,0]
Logic:
1. Prefix Pass: Fill the result array where res[i] is the product of all elements to the left.
2. Suffix Pass: Traverse backwards, multiplying each res[i] by a running suffix product.
3. Efficiency: This avoids division and O(n²) complexity, meeting the O(n) requirement.
Complexity:
  • Time: O(n) - Two linear passes.
  • Space: O(1) - Constant auxiliary space (output array doesn't count).
