68. Text Justification

Given an array of strings words and a width maxWidth, format the text such that each line has exactly maxWidth characters and is fully justified.

Pack as many words as you can in each line. Pad extra spaces evenly. If spaces don't divide evenly, the left slots get more. The last line should be left-justified.
Example 1:
Input: words = ["This", "is", "an", "example"], maxWidth = 16 Output: [ "This is an", "example " ]
Constraints:
  • 1 <= words.length <= 300
  • 1 <= maxWidth <= 100
  • words[i].length <= maxWidth
