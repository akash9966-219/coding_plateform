15. 3Sum

Find all unique triplets in an array that sum to zero.
Example 1:
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Logic:
1. Sort: Order the array to use two pointers.
2. Fix: Iterate with i, skipping duplicates.
3. Two-Pointer: Set left = i + 1 and right = end.
4. Duplicates: After finding a sum, skip identical neighbors for left and right.
Complexity:
  • Time: O(n²) - Sorting is $O(n \log n)$, but the nested loop is $O(n^2)$.
  • Space: O(log n) or O(n) - Depending on sorting implementation.
